# PROJECT CONSTITUTION — V1

## Product invariant
Build an explainable crypto technical intelligence platform, not a cheap BUY/SELL bot.

## V1 mandatory core
1. Direct exchange market-data truth.
2. Price Action / SMC / ICT engine.
3. Harmonic engine.
4. Elliott engine with competing counts.
5. Confluence without pretending it is probability.
6. Immutable signal ledger.
7. Outcome and historical evaluation.
8. Untouched-forward evidence.
9. Polished dashboard and explanations.
10. Alerts only if they do not delay core completion.

## Scientific invariants
- Point-in-time correctness is mandatory.
- Signal decision state freezes before outcome.
- Losing signals remain visible.
- Missing data is explicit.
- Historical observed frequency is not calibrated probability.
- Backtest, walk-forward and live-forward evidence remain separate.
- Ambiguity is represented, not guessed away.

## Scope firewall
Order-book intelligence, derivatives microstructure, institutional ML, autonomous research institution,
calibrated probability models, real execution and portfolio execution are V2+ unless required for V1 correctness.

## Capital boundary
`REAL_CAPITAL = 0`.
Analytics and future execution credentials/services must remain separate.
